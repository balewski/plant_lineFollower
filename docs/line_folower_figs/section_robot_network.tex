\subsection{Automatic Wi-Fi Connection and Internet Routing}
The host name is \texttt{pi2}. Wi-Fi uses a 2.4\,GHz Realtek RTL8188CUS USB adapter. The \texttt{asus-robot} profile is path A: autoconnect priority 200, address \texttt{10.0.0.20/24}, with no default route and no DNS. The spare home profile \texttt{robot-wifi} remains available at \texttt{192.168.68.126/24} with autoconnect priority 10. \texttt{select\_pi\_ethernet.sh} chooses the Ethernet profile from the cable: \texttt{asus-ethernet} at \texttt{10.0.0.120/24} when the ASUS answers, and \texttt{Wired connection 1} at \texttt{192.168.68.220/24} when the home router answers. Moving the cable among paths A, B and C selected the matching address. A reboot was not part of that check.

Desktop keeps its Internet default route and DNS on home Wi-Fi. ASUS works from its own power supply without a laptop attached; no upstream Internet is required for local Pi communication. Another laptop can join the normal \texttt{AirBears 3} SSID and reach Pi, provided clients are not isolated. The ASUS USB ports are not the laptop's network connection. A laptop using only ASUS Wi-Fi has no Internet through this isolated router unless a separate upstream arrangement is added.
