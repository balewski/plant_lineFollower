\subsection{Automatic Wi-Fi Connection and Internet Routing}
Pi uses a 2.4\,GHz Realtek RTL8188CUS USB adapter. The \texttt{asus-robot} profile has autoconnect enabled, priority 100, unlimited reconnect attempts, permanent MAC and power saving disabled. It does not accept an ASUS default route or DNS. The former home-Wi-Fi profile is retained with autoconnect disabled. These settings are applied; reboot persistence and interruption recovery still need dedicated tests.

Desktop keeps its Internet default route and DNS on home Wi-Fi. ASUS works from its own power supply without a laptop attached; no upstream Internet is required for local Pi communication. Another laptop can join the normal \texttt{AirBears 3} SSID and reach Pi, provided clients are not isolated. The ASUS USB ports are not the laptop's network connection. A laptop using only ASUS Wi-Fi has no Internet through this isolated router unless a separate upstream arrangement is added.
